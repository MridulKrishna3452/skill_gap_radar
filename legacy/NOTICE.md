# Legacy v1 (frozen)

This folder holds the original Skill Gap Radar AI v1 (Plotly Dash + SQLite) exactly as it
was before the 2.0 rebuild. It is kept for reference and for porting reusable code; it is not
part of the 2.0 build, CI or deployment.

Known issues found in the audit (not fixed here, fixed in 2.0):

- Job data is synthetic: `NaukriScraper` and `CareerPagesScraper` always generate mock jobs,
  Internshala falls back to mock jobs, and the CSV/JSON loaders create mock input files.
- The curriculum is a PDF generated by the code itself.
- The home page radar chart uses hardcoded values.
- Coverage % in `analytics/gap_analysis.py` is computed over the top 20 skills *sorted by gap*,
  which understates coverage.
- `run.py` calls `app.run_server`, which Dash 3 removed.

Code that 2.0 reuses (ported with tests, not imported from here): the normalizers in
`app/scraper/cleaning.py`, the skill alias dictionary in `app/nlp/pipeline.py`, the PDF text
extraction, the regex syllabus parser, the trend grouping and the curated roadmap text.

To run v1 anyway: `cd legacy && pip install -r requirements.txt && python run.py`
(pin `dash<3` first).
